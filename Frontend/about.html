About BatTrip & SpiderRoam

BatTrip & SpiderRoam is an AI-powered smart tourism platform designed to make travel planning easier, smarter and more budget-friendly.

🎯 Our Objective

The main objective of this project is to help travelers plan trips according to their destinations, interests, available budget, travel duration and transportation preferences.

🤖 AI & Machine Learning

The system uses tourism data and machine learning techniques to recommend suitable tourist places based on user preferences.

Technologies include TF-IDF, Cosine Similarity, Pandas, NumPy and Scikit-learn.
